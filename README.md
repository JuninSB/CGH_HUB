# Open source and keyless dandy's world script.

Run it using:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/JuninSB/CGH_HUB/refs/heads/main/loader.lua"))()
```

### You can give a look at the code and make a modded version if you want:

+ **icon.jgp** - *icon.*
+ **loader.lua** - *a simple loader for the script.*
+ **main.lua** - *the main script source code.*
+ **special_items.lua** - *a remote table that you can change and edit the default Item ESP configuration/editable items. (script has a local table for fallback too.)*
